## about
A simple tool for monitoring CPU freqs & power usage (AMD CPUs only). Handy for testing overclocks.

Power draw stats require root.

Waybar integration might come in the future with eg `--json` flag (setuid may be required).

## build
`make`

## AUR
`yay -S catproccpuinfogrepmhz`
